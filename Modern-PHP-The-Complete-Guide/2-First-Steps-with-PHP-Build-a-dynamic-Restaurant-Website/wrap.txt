*** 10. A first PHP file and the `echo` command: Display text on a website ***
- Creating Our First PHP File
Let's now create our first PHP file. To do this, we can open our code editor.

In the previous chapter, we set up the web server properly, so we will assume that we already have a folder open within our web server directory.

01-first-steps.php

Then, within the <body> tag, we can add an <h1> element:

This is standard HTML. But how can we access this file?

To view our PHP file in a browser, we need to ensure it is stored within our web server's directory. 
In our case, all files for this course are stored in a subfolder named php, but this name is arbitrary.

- Understanding PHP in an HTML File
At first glance, this file appears to be just an HTML document. 
However, because it has a .php extension, the web server knows that PHP is enabled.
When the browser requests this file, the server processes any PHP code before sending the result back.

- PHP integrates seamlessly with HTML, meaning that any standard HTML file can also be a PHP file.
If there is no PHP code, the file will simply be displayed as normal HTML.
However, since PHP is enabled, we have the ability to insert dynamic content.

-------------------code----------------------

?>

-------------------code----------------------

*** 11. The Basics of Text Generation with PHP: Create dynamic background colors ***
PHP and HTML Generation
- Overview of PHP and HTML
PHP is used to generate HTML, and the browser displays this HTML code.
PHP essentially outputs HTML or text that the browser then interprets and displays.
The browser doesn’t care how the HTML is generated, as long as it’s valid HTML.

- How PHP Generates HTML
PHP code can output arbitrary text or HTML.
Example:
-------------------code----------------------
<h1>Hello from PHP</h1>
-------------------code----------------------
When a PHP file is requested (e.g., a .php file), the server processes the PHP code, and PHP generates the corresponding HTML,
which is sent to the browser.
PHP executes and outputs the HTML as instructed, and then it forwards the rest of the code to the browser.

- Understanding Browser Behavior
The browser receives and displays the HTML, regardless of whether it was generated by PHP or written directly in the file.
PHP acts as a server-side processor, and once the HTML is generated, the browser treats it like any other HTML.

Key Points:
The browser only cares about the HTML output.
It doesn't matter if PHP generated the HTML or if it was part of the original document.

- Example with CSS
CSS can be used alongside PHP-generated HTML to style elements.
Example CSS:
-------------------code----------------------
<style>
    .body-1 { background-color: red; }
    .body-2 { background-color: green; }
    .body-3 { background-color: aqua; }
    .body-4 { background-color: yellow; }
    .body-5 { background-color: magenta; }
    .body-6 { background-color: gray; }
</style>
-------------------code----------------------
If PHP generates HTML with class names or IDs, the browser will apply the corresponding CSS without needing to know how it was generated.

- Dynamic Content Generation
PHP can generate dynamic content, like a random number, and use it in the page layout.
Example:
-------------------code----------------------
<body class="body-<?php echo rand(1, 6); ?>">
-------------------code----------------------
Every time the page is refreshed, the PHP-generated number will determine the class applied, resulting in dynamic changes (e.g., different background colors).

- PHP Output in Action
When the page is refreshed, PHP executes and outputs different HTML based on the dynamic content.
Example: A randomly generated background color will change each time the page is reloaded.

Key Takeaways:
The browser does not know how the HTML is generated.
PHP's role is to dynamically generate HTML based on the code, and then the browser just displays that HTML.

- PHP Source Code and HTML
PHP is used to generate the HTML source code, and the browser will display it once PHP has executed.
This is the core advantage of PHP: it enables server-side generation of dynamic content, and the browser only sees the final HTML result.


*** 12. The `include` command: Combine multiple PHP files ***
Using PHP Include to Split Code into Multiple Files
- Purpose of Splitting Code
Goal: Split PHP code into multiple files to create a common structure shared across different pages.
Benefit: Simplifies the deployment of HTML websites by reusing common HTML parts like headers, footers, etc.

- The include Command
PHP allows you to load external files into the current file using the include command.
Syntax:
-------------------code----------------------
include 'filename.php';
-------------------code----------------------
By default, the file should be in the same directory as the script.

- Example of Using include
Creating Files:
Create a file named start.php.
Inside start.php, use include to load another file called other.php:
-------------------code----------------------
include 'other.php';
-------------------code----------------------
Creating the Included File:
Create a file named other.php with some HTML or PHP content:
-------------------code----------------------
<p>I am the other.php file.</p>
-------------------code----------------------
Result:
When you execute start.php, PHP will include the content of other.php, and the browser will display the HTML from other.php.

- Handling Errors
If the file to be included does not exist, PHP will generate an error, as shown in the example:

-------------------code----------------------
Warning: include(other.php): failed to open stream: No such file or directory in start.php on line 2
Solution: Ensure the file exists or correct the file path.
-------------------code----------------------

- File Extensions
PHP files are typically .php, but you can include files with different extensions (e.g., .txt).
Example:
You can include other.txt and PHP will still execute the content inside if it contains PHP code.
-------------------code----------------------
<?php echo rand(1, 6); ?>
-------------------code----------------------

- Best Practices
Best Practice: Always use .php file extensions for included files to avoid confusion and ensure the proper execution of PHP code.
Example:
Including a .txt file works, but it’s better to use .php for clarity and consistency.
-------------------code----------------------
include 'other.txt'
-------------------code----------------------

7. Using Comments to Prevent Code Execution
You can comment out a line using // to prevent it from being executed.

Example:
-------------------code----------------------
// include 'other.txt';
-------------------code----------------------

- 8. Creating Full HTML Structure
Instead of just including small pieces of content, you can create an entire HTML structure and dynamically load content using PHP.

Example:

-------------------code----------------------
<!DOCTYPE html>
<html lang="en">
<head>
    <title>My Page</title>
</head>
<body>
    <?php include 'other.php'; ?>
</body>
</html>
Result: The HTML structure is defined in the file, and the content is dynamically loaded from other.php.
-------------------code----------------------

- Benefits of Using include
Reusability: You can create common structures (like headers and footers) and include them in multiple files, ensuring consistency.
Modularity: Break down large files into smaller, manageable chunks.


Summary
The include command allows us to split our PHP code into smaller files, making the development process more modular.
It enables us to create a shared structure (like HTML headers/footers) across different pages of a website.
While include works with files of different extensions, it's best to use .php files to ensure proper execution of PHP code.


*** 13. Variables in PHP: Store and access data dynamically ***

- Using Variables in PHP
Introduction to Variables
Variables are used to store values, making it easier to reuse data without repetition.
Syntax: Variables in PHP start with a $ sign followed by the name of the variable.

- Basic Example of Output
Output Without Variables:
You can simply use echo to print something like this:
-------------------code----------------------
echo "Hello PHP!";
echo "Hello PHP!";
echo "Hello PHP!";
echo "Hello PHP!";
echo "Hello PHP!";
-------------------code----------------------

- Using Variables
To avoid repeating the same value multiple times, you can store the value in a variable.
Example:
-------------------code----------------------
$greeting = "Hello PHP!";
echo $greeting;
-------------------code----------------------
The variable $greeting now holds the value "Hello PHP!", and it can be used multiple times.

- Changing Variable Values
The advantage of using variables is that if you need to change the value, you only need to change it in one place.

Example:
-------------------code----------------------
$greeting = "Hello PHP on Mars!";
echo $greeting;
-------------------code----------------------
This will output "Hello PHP on Mars!" without needing to modify multiple echo statements.

- Multiple Variables
You can define multiple variables in a PHP file.

Example:
-------------------code----------------------
$greeting = "Hello PHP on Mars!";
$year = 2050;
echo $greeting;
echo $year;
-------------------code----------------------
Result: Outputs "Hello PHP on Mars!" and "2050".

6. Using Variables in HTML
Variables are particularly useful for generating dynamic HTML content.

Example:
Define a variable for the page title in PHP:
-------------------code----------------------
<?php
  $title = 'PHP is amazing!!!';
?>
-------------------code----------------------
Use this variable inside HTML:

-------------------code----------------------
<?php
    $title = 'PHP is amazing!!!';
?><!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title><?php echo $title; ?></title>
</head>
<body>
    <h1><?php echo $title; ?></h1>
</body>
</html>
-------------------code----------------------
Result: The page title and the H1 element will both display "PHP is Amazing".

- Benefits of Using Variables
Reusability: You only need to change the value of a variable in one place to update it throughout the document.
Maintainability: Makes it easier to manage and update values, especially when the same value is needed in multiple places.
Dynamic Content: You can change the content of your page dynamically based on variables, making your pages flexible.

- Example of Modifying Variable Values
Initial value:
-------------------code----------------------
$title = "PHP is Amazing!";
-------------------code----------------------

Change value by adding emphasis:
-------------------code----------------------
$title = "PHP is AMAZING!!!";
-------------------code----------------------
Result: The page title and header reflect the updated value dynamically.

PHP variables are an essential tool for storing and reusing data efficiently.
