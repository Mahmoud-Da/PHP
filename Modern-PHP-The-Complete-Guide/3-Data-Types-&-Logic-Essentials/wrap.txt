*** 20. Strings within Single Quotes & Combine Strings with the Dot (`.`) Operator ***
- Introduction to Strings
In this lecture, we will start exploring how strings work in PHP. To demonstrate this, we will use a simple website with a basic HTML structure 
and a lightweight CSS framework called Simple CSS.

The <pre> Tag and Its Importance
The <pre> (Preformatted) tag is useful for displaying text exactly as it appears in the code, including whitespace and line breaks. Without it, a browser would collapse multiple spaces into a single space. Using the <pre> tag ensures that:
Line breaks in the code are also displayed as line breaks in the browser.
White spaces are preserved without needing to view the page source.
Writing PHP Inside the <pre> Tag
Within the <pre> tag, we can start a PHP block to execute PHP code. PHP ignores additional whitespace unless we explicitly print something using echo or another output command.

- Defining and Outputting Strings

Strings in PHP are collections of characters enclosed within single or double quotes. Examples:

// Using single quotes
-------------------code----------------------
echo 'I am a string';
-------------------code----------------------

However, if a single quote is used within a string, it must be escaped using a backslash (\):
-------------------code----------------------
echo 'I\'m a string';
-------------------code----------------------

Escaping prevents PHP from misinterpreting the single quote as the end of the string.

- Storing Strings in Variables
Instead of directly outputting strings, we can store them in variables and use them later:
-------------------code----------------------
$greeting = 'Hello, World!';
echo $greeting;
-------------------code----------------------

String Concatenation

In PHP, strings can be combined using the concatenation operator (.):
-------------------code----------------------
$greeting = 'Hello';
$name = 'Janice';
echo $greeting . ', ' . $name . '!';
-------------------code----------------------

This outputs:
Hello, Janice!

- Using Variables Inside Strings
We can also insert variables into strings dynamically:
-------------------code----------------------
$name = 'Janice';
$subject = 'PHP';
echo "I'm $name and I'm learning $subject.";
-------------------code----------------------
This method only works with double-quoted strings. With single quotes, variables are treated as plain text.

*** 21. Strings within Double Quotes: Utilize Variable Substitution & Special Characters ***

1. Introduction
Strings in PHP can be defined using either single quotes (`'`) or double quotes (`"`). While both approaches yield the same result in many cases, there are key differences in functionality.

2. Defining Strings with Double Quotes
Using double quotes provides additional flexibility. For example:
-------------------code----------------------
$string = "I'm learning PHP";
echo $string;
-------------------code----------------------
This works without requiring escape characters because single quotes are allowed inside double-quoted strings.

3. Differences Between Single and Double Quotes
3.1 Escaping Characters
- **Double Quotes**: To include a double quote inside a double-quoted string, you must escape it using `\`:
-------------------code----------------------
$string = "I am learning \"PHP\"";
-------------------code----------------------
- **Single Quotes**: To include a single quote inside a single-quoted string, escape it using `\`:
-------------------code----------------------
$string = 'I'm learning PHP';
-------------------code----------------------

3.2 Variable Interpolation
- Double Quotes: Variables inside double-quoted strings are parsed and replaced with their values:
-------------------code----------------------
$greeting = "Hello";
echo "$greeting, world!"; // Output: Hello, world!
-------------------code----------------------

- Single Quotes: Variables are treated as plain text and not expanded:
-------------------code----------------------
echo '$greeting, world!'; // Output: $greeting, world!
-------------------code----------------------

3.3 Using Curly Braces for Variable Parsing
To avoid ambiguity when using variables inside double quotes, curly braces `{}` can be used:
-------------------code----------------------
$name = "Yannis";
echo "My name is {$name}!"; // Output: My name is Yannis!
-------------------code----------------------

4. Special Characters in Double-Quoted Strings
Certain escape sequences are supported in double-quoted strings:
- `\n` (New line)
- `\t` (Tab)
- `\"` (Double quote)
- `\$` (Dollar sign)

Example:
-------------------code----------------------
echo "Hello\nWorld";
// Output:
// Hello
// World
-------------------code----------------------
Single-quoted strings do not interpret these special characters:
-------------------code----------------------
echo 'Hello\nWorld';
// Output: Hello\nWorld
-------------------code----------------------

5. Handling Line Breaks in HTML
When outputting text to an HTML page:
- `\n` creates a line break in the source code but is ignored by the browser.
- `<br>` should be used to create visible line breaks:
-------------------code----------------------
echo "First Line<br>Second Line";
-------------------code----------------------

6. Best Practices: When to Use Single vs. Double Quotes
Prefer Single Quotes When:
- No variable interpolation is needed.
- The string contains `$` symbols that are not variables.
- Performance is a concern (single quotes are slightly faster because they avoid variable parsing).

Use Double Quotes When:
- Variables need to be included directly inside the string.
- Special characters like `\n`, `\t` need to be used.
- Readability is improved by avoiding concatenation (`.` operator).

7. Conclusion
Both single and double quotes can define strings, 
but double quotes provide more flexibility with variable interpolation and escape sequences. Choosing the right approach depends on the specific
requirements of the code.


*** 22. Numbers ***

1. Basic Number Usage
- Numbers in PHP can be used without quotes.
- Example: `echo 42;` outputs `42`.
- PHP evaluates and echoes mathematical expressions directly.

2. Using Variables
- Variables can store numbers and be used in calculations.
- Example:
-------------------code----------------------
$meaning = 42;
echo $meaning * 2; // Outputs 84
-------------------code----------------------

3. Combining Calculations and Strings
- Numbers can be converted to strings for better formatting.
- Example:
-------------------code----------------------
echo (42 * 2) . "\n";
-------------------code----------------------
- This ensures the output appears correctly with line breaks.

4. Performing Arithmetic Operations
- Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`) can be performed.
- Example:
-------------------code----------------------
echo 42 / 2;  // Outputs 21
echo 42 + 2;  // Outputs 44
echo 42 - 2;  // Outputs 40
echo 42 * 2;  // Outputs 84
-------------------code----------------------

5. PHP’s Automatic Type Conversion
- PHP attempts to convert strings into numbers when possible.
- Example:
-------------------code----------------------
echo "5" + "6";  // Outputs 11
-------------------code----------------------
- If a string contains non-numeric characters, conversion may fail, leading to a fatal error.
- Example of failure:
-------------------code----------------------
echo "five" + "six";  // Fatal error: Unsupported operand types
-------------------code----------------------
- PHP may also truncate non-numeric characters and issue warnings.

6. Rounding Numbers
- PHP provides a `round()` function for rounding numbers.
- Example:
-------------------code----------------------
echo round(3.33, 1);  // Outputs 3.3
-------------------code----------------------
- Floating-point numbers can sometimes introduce rounding errors due to binary representation, and using `round()` helps mitigate this.

7. Using Arithmetic Shortcuts
- Instead of writing full expressions, PHP allows shorthand operators:
-------------------code----------------------
$meaning = 42;
$meaning *= 2; // Equivalent to $meaning = $meaning * 2;
-------------------code----------------------
- Other shorthand operations:
-------------------code----------------------
$meaning /= 2; // Division
$meaning += 2; // Addition
$meaning -= 2; // Subtraction
-------------------code----------------------
- These shortcuts modify the variable directly.

8. Summary
- PHP allows simple numerical operations with flexibility.
- It automatically converts compatible types but can fail with improper inputs.
- Rounding and arithmetic shortcuts help manage numbers efficiently.

This guide provides a structured approach to understanding how numbers work in PHP.


*** 25. The `var_dump` function: Inspect Variables ***

Introduction
The var_dump function is one of the most important debugging tools in PHP. 
It provides far more information than a simple echo, making it perfect for debugging.

How to Use var_dump
To use var_dump, simply invoke the function
using parentheses and pass in the data you want to inspect.

-------------------code----------------------
var_dump("Hello from var_dump");
-------------------code----------------------
Output in the browser:
-------------------code----------------------
string(21) "Hello from var_dump"
-------------------code----------------------

This output indicates:
The value of the string
The data type (string)
The length of the string (21 characters)
Character Count Considerations
The character count may not always match the visible characters due to encoding differences.

Some special characters require more bytes in memory.
Example: A special character might take up 4 bytes instead of 1.

Example:
-------------------code----------------------
var_dump("Ä"); // A German character  
-------------------code----------------------
This might show a length of 2 instead of 1 due to its internal representation.

Using var_dump with Different Data Types
1. Strings
-------------------code----------------------
var_dump("Hello World");
-------------------code----------------------
Output:
-------------------code----------------------
string(11) "Hello World"
-------------------code----------------------

2. Integers
-------------------code----------------------
var_dump(123);
-------------------code----------------------
Output:
-------------------code----------------------
int(123)
-------------------code----------------------

3. Floating-Point Numbers
-------------------code----------------------
var_dump(42.42);
-------------------code----------------------

Output (may vary slightly due to floating-point precision issues):
-------------------code----------------------
float(42.42)
-------------------code----------------------
Floating-point numbers are stored in binary form, 
which may cause slight rounding differences.

4. Type Conversion in var_dump
PHP automatically converts strings to numbers when necessary.

-------------------code----------------------
var_dump("4" + 5);
-------------------code----------------------
Output:
-------------------code----------------------
int(9)
-------------------code----------------------

Here, the string "4" is 
automatically converted to an integer before performing the addition.

5. Variables
-------------------code----------------------
$message = "Hello PHP";
-------------------code----------------------
var_dump($message);
Output:
-------------------code----------------------
string(9) "Hello PHP"
-------------------code----------------------

- Why Use var_dump?
Provides both value and data type.
Helps debug complex issues efficiently.
Shows how PHP handles type conversions.



*** 26. Booleans & Comparison Operators: Compare Values ***

- Introduction
Booleans are a fundamental data type in PHP, representing only two possible values: `true` or `false`. They are crucial in programming as they allow us to execute code based on conditions.

- Boolean Values
A boolean is simply a value that is either `true` or `false`. Instead of defining strings or numbers, we can define booleans directly:
-------------------code----------------------
$trueValue = true;
$falseValue = false;
var_dump($trueValue); // Outputs: bool(true)
var_dump($falseValue); // Outputs: bool(false)
-------------------code----------------------
Booleans can also be stored in variables and used in logical expressions.

- Boolean Comparisons
Booleans often result from comparisons in PHP. Various comparison operators generate boolean values:

-Greater Than and Less Than Operators
-------------------code----------------------
$number = 42;
var_dump($number > 13); // Outputs: bool(true)
var_dump($number < 13); // Outputs: bool(false)
-------------------code----------------------
Here, `42 > 13` evaluates to `true`, while `42 < 13` evaluates to `false`.

- Greater Than or Equal To & Less Than or Equal To
-------------------code----------------------
var_dump(13 <= 13); // Outputs: bool(true)
var_dump(42 >= 13); // Outputs: bool(true)
-------------------code----------------------
These operators check if a value is either greater than or equal to (or less than or equal to) another value.

- Equality and Identity Comparisons
PHP provides different equality operators to compare values and types:

- Loose Equality (`==`)
-------------------code----------------------
var_dump("30" == 30); // Outputs: bool(true)
-------------------code----------------------
This checks if values are equal but does **not** check their types.

- Strict Equality (`===`)
-------------------code----------------------
var_dump("30" === 30); // Outputs: bool(false)
-------------------code----------------------
Strict equality checks both value **and** type. Since one side is a string and the other is an integer, the comparison returns `false`.

- Inequality Operators
- Loose Inequality (`!=` or `<>`): Checks if values are not equal, ignoring type.
- Strict Inequality (`!==`): Checks if values or types are different.

-------------------code----------------------
var_dump("30" != 30); // Outputs: bool(false)
var_dump("30" !== 30); // Outputs: bool(true)
-------------------code----------------------

- Best Practices for Boolean Comparisons
- Prefer `===` and `!==` for more reliable comparisons.
- Avoid using `==` unless you explicitly want to allow type conversion.
- Using strict comparisons helps prevent subtle bugs that can be difficult to debug later.

- Conclusion
Booleans are an essential part of PHP, enabling conditional logic. Understanding comparison operators and using strict comparisons when necessary can lead to more stable and predictable code.
