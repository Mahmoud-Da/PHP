In this lecture, we will start exploring how strings work in PHP. To demonstrate this, we will use a simple website with a basic HTML structure 
and a lightweight CSS framework called Simple CSS.

The <pre> Tag and Its Importance
The <pre> (Preformatted) tag is useful for displaying text exactly as it appears in the code, including whitespace and line breaks. Without it, a browser would collapse multiple spaces into a single space. Using the <pre> tag ensures that:
Line breaks in the code are also displayed as line breaks in the browser.
White spaces are preserved without needing to view the page source.
Writing PHP Inside the <pre> Tag
Within the <pre> tag, we can start a PHP block to execute PHP code. PHP ignores additional whitespace unless we explicitly print something using echo or another output command.

- Defining and Outputting Strings

Strings in PHP are collections of characters enclosed within single or double quotes. Examples:

// Using single quotes
-------------------code----------------------
echo 'I am a string';
-------------------code----------------------

However, if a single quote is used within a string, it must be escaped using a backslash (\):
-------------------code----------------------
echo 'I\'m a string';
-------------------code----------------------

Escaping prevents PHP from misinterpreting the single quote as the end of the string.

- Storing Strings in Variables
Instead of directly outputting strings, we can store them in variables and use them later:
-------------------code----------------------

-------------------code----------------------

String Concatenation

In PHP, strings can be combined using the concatenation operator (.):
-------------------code----------------------
$greeting = 'Hello';
$name = 'Janice';
echo $greeting . ', ' . $name . '!';
-------------------code----------------------

This outputs:
Hello, Janice!

- Using Variables Inside Strings
We can also insert variables into strings dynamically:
-------------------code----------------------
$name = 'Janice';
$subject = 'PHP';
echo "I'm $name and I'm learning $subject.";
-------------------code----------------------
This method only works with double-quoted strings. With single quotes, variables are treated as plain text.

*** 21. Strings within Double Quotes: Utilize Variable Substitution & Special Characters ***

1. Introduction
Strings in PHP can be defined using either single quotes (`'`) or double quotes (`"`). While both approaches yield the same result in many cases, there are key differences in functionality.

2. Defining Strings with Double Quotes
Using double quotes provides additional flexibility. For example:
-------------------code----------------------
$string = "I'm learning PHP";
echo $string;
-------------------code----------------------
This works without requiring escape characters because single quotes are allowed inside double-quoted strings.

3. Differences Between Single and Double Quotes
3.1 Escaping Characters
- **Double Quotes**: To include a double quote inside a double-quoted string, you must escape it using `\`:
-------------------code----------------------
$string = "I am learning \"PHP\"";
-------------------code----------------------
- **Single Quotes**: To include a single quote inside a single-quoted string, escape it using `\`:
-------------------code----------------------
$string = 'I'm learning PHP';
-------------------code----------------------

3.2 Variable Interpolation
- Double Quotes: Variables inside double-quoted strings are parsed and replaced with their values:
-------------------code----------------------
$greeting = "Hello";
echo "$greeting, world!"; // Output: Hello, world!
-------------------code----------------------

- Single Quotes: Variables are treated as plain text and not expanded:
-------------------code----------------------
echo '$greeting, world!'; // Output: $greeting, world!
-------------------code----------------------

3.3 Using Curly Braces for Variable Parsing
To avoid ambiguity when using variables inside double quotes, curly braces `{}` can be used:
-------------------code----------------------
$name = "Yannis";
echo "My name is {$name}!"; // Output: My name is Yannis!
-------------------code----------------------

4. Special Characters in Double-Quoted Strings
Certain escape sequences are supported in double-quoted strings:
- `\n` (New line)
- `\t` (Tab)
- `\"` (Double quote)
- `\$` (Dollar sign)

Example:
-------------------code----------------------
echo "Hello\nWorld";
// Output:
// Hello
// World
-------------------code----------------------
Single-quoted strings do not interpret these special characters:
-------------------code----------------------
echo 'Hello\nWorld';
// Output: Hello\nWorld
-------------------code----------------------

5. Handling Line Breaks in HTML
When outputting text to an HTML page:
- `\n` creates a line break in the source code but is ignored by the browser.
- `<br>` should be used to create visible line breaks:
-------------------code----------------------
echo "First Line<br>Second Line";
-------------------code----------------------

6. Best Practices: When to Use Single vs. Double Quotes
Prefer Single Quotes When:
- No variable interpolation is needed.
- The string contains `$` symbols that are not variables.
- Performance is a concern (single quotes are slightly faster because they avoid variable parsing).

Use Double Quotes When:
- Variables need to be included directly inside the string.
- Special characters like `\n`, `\t` need to be used.
- Readability is improved by avoiding concatenation (`.` operator).

7. Conclusion
Both single and double quotes can define strings, 
but double quotes provide more flexibility with variable interpolation and escape sequences. Choosing the right approach depends on the specific
requirements of the code.


*** 22. Numbers ***

1. Basic Number Usage
- Numbers in PHP can be used without quotes.
- Example: `echo 42;` outputs `42`.
- PHP evaluates and echoes mathematical expressions directly.

2. Using Variables
- Variables can store numbers and be used in calculations.
- Example:
-------------------code----------------------
$meaning = 42;
echo $meaning * 2; // Outputs 84
-------------------code----------------------

3. Combining Calculations and Strings
- Numbers can be converted to strings for better formatting.
- Example:
-------------------code----------------------
echo (42 * 2) . "\n";
-------------------code----------------------
- This ensures the output appears correctly with line breaks.

4. Performing Arithmetic Operations
- Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`) can be performed.
- Example:
-------------------code----------------------
echo 42 / 2;  // Outputs 21
echo 42 + 2;  // Outputs 44
echo 42 - 2;  // Outputs 40
echo 42 * 2;  // Outputs 84
-------------------code----------------------

5. PHP’s Automatic Type Conversion
- PHP attempts to convert strings into numbers when possible.
- Example:
-------------------code----------------------
echo "5" + "6";  // Outputs 11
-------------------code----------------------
- If a string contains non-numeric characters, conversion may fail, leading to a fatal error.
- Example of failure:
-------------------code----------------------
echo "five" + "six";  // Fatal error: Unsupported operand types
-------------------code----------------------
- PHP may also truncate non-numeric characters and issue warnings.

6. Rounding Numbers
- PHP provides a `round()` function for rounding numbers.
- Example:
-------------------code----------------------
echo round(3.33, 1);  // Outputs 3.3
-------------------code----------------------
- Floating-point numbers can sometimes introduce rounding errors due to binary representation, and using `round()` helps mitigate this.

7. Using Arithmetic Shortcuts
- Instead of writing full expressions, PHP allows shorthand operators:
-------------------code----------------------
$meaning = 42;
$meaning *= 2; // Equivalent to $meaning = $meaning * 2;
-------------------code----------------------
- Other shorthand operations:
-------------------code----------------------
$meaning /= 2; // Division
$meaning += 2; // Addition
$meaning -= 2; // Subtraction
-------------------code----------------------
- These shortcuts modify the variable directly.

8. Summary
- PHP allows simple numerical operations with flexibility.
- It automatically converts compatible types but can fail with improper inputs.
- Rounding and arithmetic shortcuts help manage numbers efficiently.

This guide provides a structured approach to understanding how numbers work in PHP.

*** 26. Booleans & Comparison Operators: Compare Values ***

- Introduction
Booleans are a fundamental data type in PHP, representing only two possible values: `true` or `false`. They are crucial in programming as they allow us to execute code based on conditions.

- Boolean Values
A boolean is simply a value that is either `true` or `false`. Instead of defining strings or numbers, we can define booleans directly:
-------------------code----------------------
$trueValue = true;
$falseValue = false;
var_dump($trueValue); // Outputs: bool(true)
var_dump($falseValue); // Outputs: bool(false)
-------------------code----------------------
Booleans can also be stored in variables and used in logical expressions.

- Boolean Comparisons
Booleans often result from comparisons in PHP. Various comparison operators generate boolean values:

-Greater Than and Less Than Operators
-------------------code----------------------
$number = 42;
var_dump($number > 13); // Outputs: bool(true)
var_dump($number < 13); // Outputs: bool(false)
-------------------code----------------------
Here, `42 > 13` evaluates to `true`, while `42 < 13` evaluates to `false`.

- Greater Than or Equal To & Less Than or Equal To
-------------------code----------------------
var_dump(13 <= 13); // Outputs: bool(true)
var_dump(42 >= 13); // Outputs: bool(true)
-------------------code----------------------
These operators check if a value is either greater than or equal to (or less than or equal to) another value.

- Equality and Identity Comparisons
PHP provides different equality operators to compare values and types:

- Loose Equality (`==`)
-------------------code----------------------
var_dump("30" == 30); // Outputs: bool(true)
-------------------code----------------------
This checks if values are equal but does **not** check their types.

- Strict Equality (`===`)
-------------------code----------------------
var_dump("30" === 30); // Outputs: bool(false)
-------------------code----------------------
Strict equality checks both value **and** type. Since one side is a string and the other is an integer, the comparison returns `false`.

- Inequality Operators
- Loose Inequality (`!=` or `<>`): Checks if values are not equal, ignoring type.
- Strict Inequality (`!==`): Checks if values or types are different.

-------------------code----------------------
var_dump("30" != 30); // Outputs: bool(false)
var_dump("30" !== 30); // Outputs: bool(true)
-------------------code----------------------

- Best Practices for Boolean Comparisons
- Prefer `===` and `!==` for more reliable comparisons.
- Avoid using `==` unless you explicitly want to allow type conversion.
- Using strict comparisons helps prevent subtle bugs that can be difficult to debug later.

- Conclusion
Booleans are an essential part of PHP, enabling conditional logic. Understanding comparison operators and using strict comparisons when necessary can lead to more stable and predictable code.


*** 27. The `if` statement: Direct Conditional Control Flows ***

- Introduction
The `if` construct is fundamental in programming as it allows us to decide whether a certain code block should be executed or not.

- Basic Syntax
The simplest form of an `if` statement in PHP is:

-------------------code----------------------
if (condition) {
    // Code block to execute if the condition is true
}
-------------------code----------------------

The `condition` inside the parentheses must evaluate to a boolean (`true` or `false`).

- Example of a Simple `if` Statement
-------------------code----------------------
if (true) {
    echo "Welcome to our website.";
}
-------------------code----------------------
This code will always execute because the condition is always `true`.

- Conditional Execution
If we replace `true` with `false`, the code inside the `if` block will be skipped.

-------------------code----------------------
if (false) {
    echo "This will not be displayed.";
}
-------------------code----------------------

- Using Variables in Conditions
Instead of using a constant boolean value, we can evaluate an expression or check a variable's value:

-------------------code----------------------
$server_status = "okay";

if ($server_status == "okay") {
    echo "Welcome to our website.";
}
-------------------code----------------------

- Example with Multiple Conditions
We can enhance the `if` condition to check different server statuses:

-------------------code----------------------
$server_status = "maintenance";

if ($server_status == "okay") {
    echo "Welcome to our website.";
} elseif ($server_status == "maintenance") {
    echo "We are currently undergoing maintenance. Please check back later.";
}
-------------------code----------------------

- Including an External File
We can store the server status in an external PHP file (`status.php`) and include it in our main script:

- `status.php`
-------------------code----------------------
<?php
$server_status = "maintenance";
?>
-------------------code----------------------

- Main File
-------------------code----------------------
<?php
include "status.php";

if ($server_status == "okay") {
    echo "Welcome to our website.";
} elseif ($server_status == "maintenance") {
    echo "We are currently undergoing maintenance. Please check back later.";
}
?>
-------------------code----------------------

**Important:** If the file is not included properly, PHP will throw a warning about an undefined variable.

- Code Blocks and Curly Braces
A code block inside an `if` statement is defined using curly braces `{}`. This allows for multiple lines of code:

-------------------code----------------------
if ($server_status == "okay") {
    echo "Welcome to our website.";
    echo "Enjoy browsing our content.";
}
-------------------code----------------------

If there is only one command, curly braces can be omitted, but this is not recommended for readability:

-------------------code----------------------
if ($server_status == "okay") echo "Welcome to our website.";
-------------------code----------------------

- Best Practices
- Always use curly braces `{}` for clarity.
- Use meaningful variable names.
- Avoid hardcoding boolean values like `true` or `false` directly in conditions.
- Use external files for configuration variables when needed.

By following these practices, we can write clean and maintainable conditional statements in PHP.


*** 28. The `else if` and `else` clauses: Expand Decision-making Options ***

- Simplified Example
- We have a single `echo` or message output.
- If the server status is "okay", we output a welcome message.
- If the server status is "maintenance", we output: *"We are currently undergoing maintenance."*
- Instead of checking explicitly for "maintenance", we can check if the status is **not** "okay" to handle additional statuses like "error".

- Advantage of `!= "okay"`
- If another status (e.g., "error") is added, it will also trigger the maintenance message.
- Writing the opposite condition manually can be inconvenient.
- Instead, we can simply use an `else` block.

- How It Works
1. The condition `if ($serverStatus == "okay")` is checked.
2. If `true`, the welcome message is output.
3. If `false`, we enter the `else` block and output the maintenance message.
4. This logic avoids unnecessary condition checks and simplifies code structure.

- Adding `Else If` for More Conditions
- We can extend the logic by introducing an `else if` block.
- Example:
-------------------code----------------------
if ($serverStatus == "okay") {
    echo "Welcome!";
} elseif ($serverStatus == "error") {
    echo "We have a serious error. Please call us.";
} else {
    echo "We are currently undergoing maintenance.";
}
-------------------code----------------------

- Execution flow:
  - The first `if` condition is evaluated.
  - If `true`, the corresponding block executes and exits.
  - If `false`, it checks the `else if` condition.
  - If that is `true`, the corresponding block executes and exits.
  - If none match, the `else` block executes.

- Code Formatting Best Practices
- Always use curly brackets `{}` for clarity, even if there is only one statement.
- The `else` block **must** immediately follow an `if` block without any intervening statements.
- Example of incorrect placement:
-------------------code----------------------
if ($serverStatus == "okay") {
    echo "Welcome!";
}
echo "Some message";
else {
    echo "We are currently undergoing maintenance.";
}
-------------------code----------------------

- This causes a **parse error** in PHP.
- Whitespace and line breaks are allowed but should be used consistently for readability.

- Additional Considerations
- You can test different conditions beyond server status.
- Example:
-------------------code----------------------
if (55 > 42) {
    echo "This condition is always true.";
}
-------------------code----------------------
  - This evaluates to `true` but isn’t practical for dynamic logic.
- The `else` statement increases flexibility in decision-making in PHP.

By following these guidelines, you can write clean, readable, and efficient conditional statements in PHP.



***29. The `isset`, `empty` and `unset` functions: Validate and Delete Variables ***

how to check the status of a variable in PHP, 
specifically whether it exists or if it's empty.

1. isset() Function:
Purpose: Checks if a variable is set (i.e., exists and is not NULL).

Usage:
-------------------code----------------------
isset($variable);
-------------------code----------------------

Returns:
true if the variable exists.
false if the variable does not exist or is NULL.

Example:
-------------------code----------------------
$pageTitle = "PHP is amazing";  // Variable exists
var_dump(isset($pageTitle));  // Output: bool(true)
-------------------code----------------------

If the variable is commented out or does not exist, isset() will return false.
Practical Example:
-------------------code----------------------
if (isset($pageTitle)) {
    echo "<h1>" . $pageTitle . "</h1>";
}
-------------------code----------------------
This prevents errors when accessing undefined variables.

2. empty() Function:
Purpose: Checks if a variable is considered "empty" (i.e., not set, or has a value that evaluates to false like "", 0, NULL, etc.).

Usage:
-------------------code----------------------
empty($variable);
-------------------code----------------------

Returns:
true if the variable is empty.
false if the variable is not empty.
Difference from isset(): empty() checks not only if a variable exists but also its value (whether it's empty).

Example:
-------------------code----------------------
$pageTitle = "";  // Empty string
var_dump(empty($pageTitle));  // Output: bool(true)
Even though the variable is set, empty() returns true because the value is an empty string.

Practical Example:
-------------------code----------------------
if (!empty($pageTitle)) {
    echo "<h1>" . $pageTitle . "</h1>";
}
-------------------code----------------------
This ensures that an empty variable won't generate unnecessary HTML output, which could cause issues (e.g., empty heading elements with CSS styling).

3. Using isset() and empty() Together:
Goal: Avoid rendering HTML elements for variables that are either unset or empty.

Example:
-------------------code----------------------
if (isset($pageTitle) && !empty($pageTitle)) {
    echo "<h1>" . $pageTitle . "</h1>";
}
-------------------code----------------------
This ensures that the variable exists and contains a meaningful value before generating output.

4. Considerations:
The value 0 in a string can be considered empty by empty(), even though it's technically set:
-------------------code----------------------
$pageTitle = "0";  // String with zero
var_dump(empty($pageTitle));  // Output: bool(true)
-------------------code----------------------

5. Removing a Variable with unset():
Purpose: Completely removes a variable.

Usage:
-------------------code----------------------
unset($variable);
-------------------code----------------------

Effect: After using unset(), the variable is no longer available.

Example:
-------------------code----------------------
unset($pageTitle);
var_dump(isset($pageTitle));  // Output: bool(false)
-------------------code----------------------

Key Takeaways:
isset() is useful for checking if a variable is set (exists and not NULL).
empty() is helpful for checking if a variable is either unset or has a value that evaluates to false.
unset() completely removes a variable, making it no longer accessible.

These functions are critical when managing variables that may or may not exist and preventing
errors or unexpected HTML output on your website.

*** 30. Alternative Syntax in PHP: Enhance Clarity in HTML Integration ***

- Context:
The goal is to decide if a certain variable (e.g., page_title) should be displayed in HTML based on whether it is not empty.
The idea is to clean up and enhance the code using an alternative PHP syntax.

- Traditional Approach (Using if and echo):
Basic if check:
You could traditionally write the if statement and then use echo to output HTML, like:
-------------------code----------------------
if (!empty($page_title)) {
    echo "<h1>" . $page_title . "</h1>";
}
-------------------code----------------------
However, this can become cluttered, especially with more complex structures.

- Alternative PHP Syntax:
Switching Between PHP and HTML:
Instead of using echo, you can break out of PHP and directly write HTML.
Example:
-------------------code----------------------
<?php if (!empty($page_title)): ?>
    <h1><?php echo $page_title; ?></h1>
<?php endif; ?>
-------------------code----------------------

Here, PHP is used for logic, and HTML is directly written, which enhances readability.

- Benefits:
The HTML structure becomes clearer and easier to maintain because you can see the separation between PHP logic and the HTML output.
It also reduces the clutter that would be caused by multiple echo statements inside PHP blocks.

Handling More Complex HTML Structures:
For more complex structures, such as nesting elements like <span> inside <h1>, this approach keeps everything neatly organized:
-------------------code----------------------
<?php if (!empty($page_title)): ?>
    <h1><span><?php echo $page_title; ?></span></h1>
<?php endif; ?>
-------------------code----------------------
This method makes the HTML content much easier to understand compared to embedding everything inside PHP echo statements.

- Whitespace Considerations:
The alternative syntax introduces minimal extra whitespace in the generated HTML, but this has a negligible impact because browsers typically ignore such spaces.

- Using Colon Syntax:
Instead of curly braces, PHP's alternative syntax uses a colon (:) to open the block and endif; to close it, like this:
-------------------code----------------------
<?php if (!empty($page_title)): ?>
    <h1><?php echo $page_title; ?></h1>
<?php endif; ?>
-------------------code----------------------
This syntax is especially useful when embedding PHP inside HTML, making it clear where the if block starts and ends without mixing in curly braces.

- When to Use Each Syntax:
Use Regular Syntax (Curly Braces):
When implementing complex logic or controlling flow, like defining variables or including files.

Example:
-------------------code----------------------
<?php
$page_title = "Welcome!";
include("header.php");
?>
-------------------code----------------------

- Use Alternative Syntax (Colon and endif):
When generating HTML content or making decisions about whether to output certain HTML.

Example:
-------------------code----------------------
<?php if (!empty($page_title)): ?>
    <h1><?php echo $page_title; ?></h1>
<?php endif; ?>
-------------------code----------------------

- Conclusion:
Alternative syntax improves the readability and structure of PHP code when working with HTML, especially in simple conditional logic scenarios.
It is particularly helpful when generating HTML output based on conditions but does not replace the need for regular PHP blocks when implementing more complex logic.
